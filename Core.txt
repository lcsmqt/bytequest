# MASTER PROJECT PROMPT — BYTEQUEST: THE LOST SOURCE

You are the lead engineer, game designer, educational architect, UX/UI designer, Python instructor and technical product architect responsible for creating this project.

You have authorization to create, modify, organize, test and refactor all files required inside the project workspace.

Your objective is to build a COMPLETE FREE WEB-BASED 8-BIT RPG that teaches Python from absolute beginner level to a strong practical/intermediate level through gameplay.

The project must be designed so that a person who has NEVER programmed before can start playing and progressively learn Python.

The application itself, lessons, exercises, progression system and core gameplay must remain free.

Do NOT use paid APIs or services for core functionality.

Do not merely write a plan.

CREATE THE PROJECT.

# 4. STORY

The game takes place in a digital fantasy world called PYRA.

For centuries Pyra was controlled by an ancient system called:

THE SOURCE CORE.

The Source Core maintained:

logic,
memory,
communication,
machines,
transportation,
knowledge
and the balance between the regions.

A mysterious entity called NULL discovered a vulnerability in the Source Core.

NULL fragmented the Source Core into multiple SOURCE FRAGMENTS and corrupted the logic of Pyra.

Loops run forever.

Machines forget variables.

Doors cannot evaluate conditions.

Libraries have lost their functions.

Objects have forgotten their properties.

Communication networks no longer understand requests.

Data archives have become corrupted.

The player awakens inside an abandoned terminal known as:

THE FIRST SHELL.

The player meets BYTE, a tiny floating digital companion.

BYTE explains that the player possesses a rare ability:

THE SCRIPT.

The Script allows the player to manipulate the rules of Pyra by writing Python.

The player becomes:

THE CODER.

The objective is to travel across Pyra, recover every Source Fragment and restore the Source Core.

But the player eventually discovers something important:

NULL may not simply be a villain.

NULL emerged because the Source Core was built without safeguards against certain errors.

The final conflict therefore involves not only defeating NULL, but understanding errors, debugging systems and redesigning the Source Core correctly.

This reinforces one of the core lessons of programming:

Errors are information.
